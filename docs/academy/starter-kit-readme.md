# DANINI AI Business Starter Kit — v0.1 (DE / SR)
**Interni status:** stvarne radne datoteke u pripremi; **nije ponuđeno kao gotov plaćeni proizvod; javna naplata nije aktivirana.**

## Sadržaj / Inhalt
- Modul 01: već implementirana besplatna online lekcija i petopoljna PDF/print radna sveska na `/de/akademija/` i `/sr/akademija/`.
- Modul 02: `module-02-de.md` i `module-02-sr.md` — istraživanje tržišta, tri prompta, dva primera i radna sveska.
- `starter-kit-worksheet.csv` — evidencija izvora, konkurenata, statusa dokaza i odluka.
- `starter-kit-offer-template-de-sr.md` — mali početni nacrt poslovne ponude.
- `starter-kit-validation-checklist-de-sr.md` — kontrolna lista za testiranje prve ideje.

## Predloženi put korisnika / Lernpfad
1. Odaberi nišu u Modulu 01 / Nische im Modul 01 eingrenzen.
2. Popuni Module 02 istraživački dosije / Recherche-Dossier ausfüllen.
3. Popuni ponudu sa ograničenjem opsega / Angebot mit Leistungsgrenze formulieren.
4. Definiši jedan mali test i STOP uslov / Validierungstest mit STOP-Kriterium planen.
5. Iznesi odluku PASS / NEEDS_REVIEW / STOP; izostanak dokaza nije neuspeh / fehlende Evidenz transparent markieren.

**Ne mešati edukativni paket sa garancijom zarade, punim poslovnim savetovanjem, zvaničnom stručnom proverom ili autonomnim AI servisom.** Pre javne ponude proveriti dostupnost datoteka, ispravan opis, dozvoljena pravila isporuke i naplate.
